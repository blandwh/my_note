# Automatic Differentiation

由于训练流程在 [流程速看](./pytorch-fast.md) 当中都有了，所以

需要知道张量和普通的向量是不同的，张量不仅仅有数值信息，同时也可能带有计算记录。`print(loss.grad_fn)` 使用这种形式，可以打印张量对应的计算记录。

`loss.backward()` 是启动反向传播计算梯度的过程，之后计算的结果存放在 `w.grad` 当中。

然而并非所有的 `.grad` 都是可以看到的，可以看下面的一个例子：

```python
a = torch.tensor(2.0, requires_grad=True)
c = a * a
```

a 是直接创建的，叫叶子张量；c 是运算得到的，属于非叶子张量。默认情况下，反向传播把梯度保存在需要梯度的叶子张量上。中间结果也参与求导，只是默认不保存自己的 .grad。因此，如果想观察 c 的梯度，可以在反向传播前写：`c.retain_grad()`。

需要注意中间变量是可以求导的（不然也没办法反向传播了），只是说不一定会保存相应的梯度。

有的时候我们可能不希望记录求导关系，比如需要冻结神经网络当中的参数，或者仅使用前向传播做预测的时候。可以采用如下方式：

```python
with torch.no_grad():
    z = torch.matmul(x, w) + b
```
