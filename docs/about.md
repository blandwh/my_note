# 关于这个笔记本

你好，我是 **blandwh**。这里是一座持续生长的个人数字花园，用来沉淀学习过程中的理解，而不仅仅是收藏资料。

## 内容说明

- **课程笔记**：围绕一门课程组织，强调知识脉络、推导与复习。
- **Paper Note**：围绕一篇论文组织，记录问题、方法、实验和个人判断。
- **杂项 Misc**：工具使用、技术踩坑、随想以及暂时无法分类的内容。
