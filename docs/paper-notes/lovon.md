# LOVON: Legged Open Vocabulary Object Navigator

[论文链接](https://arxiv.org/abs/2507.06747)｜[代码仓库](https://github.com/DaojiePENG/LOVON)

## 解决的问题

论文研究腿式机器人在开放环境中的长序列目标导航：机器人需要理解自然语言任务，依次寻找并接近多个物体，并在相机抖动、目标移动或暂时丢失时继续完成任务。

## 问题必要性

现有研究通常只关注单一目标或底层运动控制，且依赖固定类别检测。真实环境中，机器人还会遇到运动模糊、遮挡、动态目标和复杂语言指令，因此需要把语言规划、视觉感知和运动控制组成稳定的闭环系统。

## 论文方案

LOVON 主要包含：

* LLM：将长任务拆分成多个子任务；
* IOE：从指令中提取目标物体；
* YOLO-World：检测目标及其位置；
* 模糊帧过滤与移动平均：减小相机抖动和检测框波动；
* L2MM：根据任务、检测结果和当前状态，输出速度向量及下一状态；
* 搜索状态机：目标丢失后控制机器人左右旋转，重新寻找目标。

L2MM 使用规则生成的 100 万条合成数据训练，本质上是在学习人工设计的视觉伺服和状态转换规则。

## 实验效果

LOVON 在 Gym-Unreal 仿真中取得接近 100% 的成功率，表现与 TrackVLA 接近，但训练时间和模型规模更小。模糊过滤与四状态搜索机制明显减少了 backpack、chair 等难检测目标的搜索次数和完成时间。系统还成功部署到 Unitree Go2、B2 和 H1-2 上，展示了多目标导航、动态跟踪和干扰恢复能力。

## 优点

* 系统模块化，整体流程清晰；
* 模型轻量，适合边缘设备部署；
* 训练成本较低；
* 目标丢失后具有主动恢复能力；
* 能适配多种腿式机器人。

## 局限

* L2MM 不直接处理图像，只使用 YOLO 的检测结果；
* 训练标签来自人工规则，缺少与直接规则控制器的比较；
* 当前代码主要支持 COCO 80 类，开放词汇能力有限；
* 真实机器人实验以展示为主，缺少成功率、延迟等定量数据；
* 缺少深度感知、避障、建图和全局路径规划。
